# SIDEREA: An Auditable Pipeline for Human-Supervised Optical Transient Triage

Main source: `siderea_transient_triage.tex`

Bibliography: `references.bib`

Local arXiv layout package: `arxivrefined.sty`

Research synthesis and claim-audit working files are stored under `research/`.
The completed scientific and production assessment is in `AUDIT.md`.

Build with a standard LaTeX distribution:

```bash
latexmk -pdf siderea_transient_triage.tex
```

Or build with Tectonic:

```bash
tectonic --keep-intermediates siderea_transient_triage.tex
```

The checked build also retains `siderea_transient_triage.bbl`, which should be included
with the source bundle when required by an arXiv submission workflow.

The XeTeX/Tectonic layout resolves TeX Gyre Termes, Heros and Cursor from the
TeX distribution by filename. It does not require Times New Roman, Helvetica
or Menlo installed on the operating system. The pdfLaTeX route retains its
Times/Helvetica-compatible TeX fonts and may paginate differently.

Historical figures come from `figures/make_figures.py`. Synthetic search figures
and per-trial results come from `experiments/run_transient_search.py` and
`experiments/run_noise_stress.py`; see `../docs/TRANSIENT_SEARCH.md` for commands.
These experiment directories preserve separate protocols and source snapshots.
Use new output directories when reproducing them; never overwrite earlier results.

The manuscript is deliberately framed as a legacy operational audit plus an
implementation-level SIDEREA safety analysis, not a classifier benchmark. The stage
totals are not a closed cohort, and software tests are not scientific validation;
preserve both caveats when adapting the text or abstract.

The author block contains Aadi Ajeesh Nair and Ryan Gomez. Author order, affiliations, target-venue requirements and final approval still require author confirmation.
If a journal-specific version is needed, convert the document class while
preserving the decision-state semantics, cohort caveats, and figure captions.


## Reconstruct the reported numerical studies

From the repository root, use the current checkout in a Python environment with
`python -m pip install -e '.[visualization]'`, then run:

```sh
python paper/reconstruct.py --output /absolute/path/to/new-reconstruction
```

The destination must not exist. The command copies the explicitly selected source,
protocol and paper inputs into `workspace/`, records a SHA-256 input manifest and
installed dependency inventory, regenerates the historical figures and 50,000-draw
bootstrap, and reruns the IID, supplied-covariance and seven-scenario null studies.
All subprocesses import SIDEREA from the copied source. It compares result rows,
protocol identities and trial-statistic digests with the archived reference results.
Nonzero exit means reconstruction failed; `reconstruction.json` and per-command
logs retain the failure. Expected new runtime timestamps and renderer-dependent
image bytes are not used as scientific equality tests.

This reconstructs the reported numerical studies, not unavailable historical
light curves, live TNS evidence or a new ML training benchmark. Earlier baseline
and JEPA smoke evidence is archived separately. Use the copied workspace to build
the manuscript with Tectonic; redistribution remains subject to the project's
existing proprietary declaration and third-party data permissions.

The original 405-test statement remains bound to its dated source/test snapshot.
The manuscript also reports the clean 2026-09-13 release verification of revision
`4e084a795be3` (499 tests, 103 parameterized subtests, and 77.95% branch-aware
coverage) through `research/software-verification-2026-09-13.json`. Neither record
is evidence of astronomical performance. Track final work in
`FINAL_PAPER_CHECKLIST.md`.

`make paper-check` checks the reconstruction tools and their regression tests.
`make paper-reconstruct PAPER_OUTPUT=/absolute/path/to/new-directory` runs the
reconstruction using the selected `PYTHON`. Both use the repository Makefile.
The two synthetic count tables are generated by `experiments/make_tables.py`;
reconstruction rejects a manuscript table that differs from its archived results.

### Integrity checks before table generation

The reconstruction and table generator now validate each experiment archive with
`siderea.research.archives.verify_archive`: report, protocol, source-snapshot and
trial-file digests; complete, unique declared scenario/method rows; plus-one
p-values recomputed from calibration and evaluation statistics; detection counts,
fractions and Wilson intervals recomputed from the trials. Invalid evidence fails
before table output is created. These checks establish internal consistency, not
authorship or independent real-sky validation. Keep trusted release manifests separately.

Both experiment runners also reject unsupported or duplicate scenario declarations
and an imported detector that differs from the checkout being archived. Use an
editable install of this checkout, or prefix source commands with `PYTHONPATH=src`.
Noise gap and variance-change times follow the configured duration; the original
60-day protocols and their archived adverse results remain unchanged.
